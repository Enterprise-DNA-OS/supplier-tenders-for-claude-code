# Customise the tender process

Read CLAUDE.md and the schema first. Ask what field, rule or terminology the operator wants. Inspect current records and back up the database before a migration. Write a new numbered migration, never edit an applied migration. Update the CLI, views, documents and the matching command recipe. Preserve bid evidence, independent approval and decision snapshots. Test against a temporary database with npm test, then apply the migration to the approved database with npm run migrate. Describe the changed behaviour and show the resulting records. Never publish, send or spend.
