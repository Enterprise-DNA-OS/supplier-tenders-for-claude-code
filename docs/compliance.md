# Procurement record checks

Sources checked 14 October 2026. These are internal record checks for an owner-led business. Public procurement guidance is a useful reference, not a declaration that the same rules apply to every private purchase. No command certifies legal compliance, assesses all mandatory criteria or authorises spending.

| Check | Record behaviour | Source and scope |
|---|---|---|
| NZ-PROBITY | Pending or conflicted panel declarations appear in compliance and block awards. Managed declarations need evidence. | [NZ evaluation panel chair guidance](https://www.procurement.govt.nz/assets/procurement-property/documents/guide-evaluation-panel-chairs.pdf) addresses conflicts, confidentiality and records. |
| NZ-EVALUATION | Missing reviewer and criterion scores appear individually. Decisions store the evidence used. | The same NZ chair guidance addresses evaluation methodology, weights and consolidated scores. Numeric averaging here is our local policy. |
| Separate approval | Award actor must differ from owner and all panel members. | [Australian procurement process considerations](https://www.finance.gov.au/government/procurement/buying-australian-government/procurement-process-considerations) recommends separation of evaluation and spending approval. This command records an approval, it does not approve spending. |
| LOCAL-WEIGHTS | Criteria total 100 before opening. Criteria and lot edits through the CLI stop once open. | Local model for a weighted panel assessment. It is not a universal legal method. |
| LOCAL-COVERAGE | Every active supplier must quote every lot before award. Missing totals stay blank. | Local rule for a whole-tender award. Split or partial awards require a different evaluated design. |
| LOCAL-LATE-BID | Recorded late receipts block award. | Local conservative control, not a complete implementation of jurisdictional late-tender rules or exceptions. |
| LOCAL-CLARIFICATION | Unanswered questions stay visible, overdue ones are flagged, all active evaluation questions block award. | Local follow-up control. The tool does not distribute clarifications. |
| LOCAL-IMPORT and LOCAL-IMPORT-BID | Imported drafts and unknown receipt dates or lead times stay visible. | Local reconciliation policy. |

The [Australian ethics and probity guide](https://www.finance.gov.au/government/procurement/buying-australian-government/ethics-and-probity-procurement) addresses conflict management and recording decisions. The owner chooses the appropriate evaluation method. The application does not award to the highest numerical score automatically.

Confidential submissions and scores belong only with authorised reviewers. RLS is enabled with no public grants, but the trusted local operator owns the database and can see all records. This is not authenticated panel isolation or sealed-bid custody. Actor names do not establish identity. Evidence references do not prove the referenced document exists. Back up source documents separately and implement role access before using a shared deployment.

No retention period is imposed. Apply your contract, sector, privacy and legal-hold requirements with the responsible records owner. Record checks cannot replace those decisions. The system does not implement public tender publication, minimum advertisement periods, notice delivery, debrief obligations or electronic signing.
